# CausalPipe-Transfer

**Streaming Domain Adaptation for Causal Inference Pipelines**

This repository contains the code and reproducibility materials for my research paper on CausalPipe-Transfer, a framework for estimating average treatment effects (ATE) in non-stationary streaming environments across multiple domains. *(This README reflects the major-revision version of the manuscript, KNOSYS-D-26-13508.)*

## What This Paper Is About

A core challenge in applied causal inference is that real-world data distributions change over time. A causal model trained on last month's retail transactions may give misleading estimates today if customer behavior has shifted. Standard approaches either ignore this (static models) or retrain everything from scratch when drift is detected (expensive and often unnecessary).

CausalPipe-Transfer takes a different approach: it diagnoses **which component** of the causal pipeline has been affected by the shift — the propensity model, the outcome model, or both — and updates only that component. This selective ("Component-Aware") adaptation strategy is both computationally efficient and, in some cases, more accurate than full retraining (Full-Adapt), a theoretical guarantee formalized in Corollary 1 and confirmed empirically (see below).

The framework is validated on three domains:
- **Synthetic benchmarks** under five types of distributional shift (covariate, label, mechanism, mixed, gradual)
- **FreshRetailNet-50K** — a fresh food retail dataset with 335,437 transactions
- **PhysioNet 2019 Sepsis** — ICU patient encounters from the CinC Challenge 2019 (20,324 patients after cohort construction)

## Estimator

All experiments use the same Augmented Inverse Probability Weighting (AIPW) doubly robust estimator:

```
τ̂ = (1/n) Σ_i [ μ1(Xi) − μ0(Xi) + Ti(Yi − μ1(Xi))/e(Xi) − (1−Ti)(Yi − μ0(Xi))/(1−e(Xi)) ]
```

where `e(Xi)` is the propensity score and `μt(Xi)` are counterfactual outcome predictions. Confidence intervals are computed from influence-function standard errors.

**Corollary 1 (selective-adaptation variance advantage):** under covariate shift, Component-Aware adaptation (retraining only the invalidated component) has empirically confirmed lower estimator variance than Full-Adapt (retraining everything) — σ² = 0.0109 (CA) vs. 0.1102 (Full-Adapt), a ~10.1× advantage. Under label shift the two are nearly identical (σ² = 0.0009 vs. 0.0009), because Component-Aware retrains the outcome model exactly as Full-Adapt does in that case. See `experiments/synthetic/corollary1_variance_check.py`.

## Shift Detection

The propensity-calibration shift detector uses two primary signals, with a third mechanism-shift signal and a documented fallback rule (Algorithm 1):
- **Covariate shift:** KS test on propensity score distributions with Bonferroni correction (threshold α/p where p = number of features, α = 0.05)
- **Label shift:** two-sided Welch t-test on outcome residuals from the source model (α = 0.05, plus mean shift > 2σ threshold)
- **Mechanism shift:** tested only if the first two signals do not fire; KS test on residual distributions, with an explicit "otherwise → label_shift" fallback rule

Detection accuracy: 95.6% at target-window size n₂=3,000 (239/250 across the expanded shift-type × seed grid). A dedicated small-target-sample sweep (n₂ ∈ {500, 1000, 2000, 3000}) additionally shows the single-class-propensity fallback firing only at n₂=500 (3/50 covariate-shift windows, 3/50 mixed, 1/50 gradual; zero at n₂≥1000) — see `r3_major3_detection_error_mse_smallsample.py`.

## Major Corrections in This Revision

- **Retail — discount field:** the raw `discount` column is defined by the dataset as 1.0 = full price / 0.9 = 10% off, i.e. it is the *inverse* of a discount rate. The corrected treatment variable is `true_discount = 1 − discount`. See `discount_field_diagnostic.py` for the confirming diagnostic.
- **Retail — model specification:** discrete discount bins were dropped entirely (numerically unstable near the near-zero-variance mass point at "no discount") in favor of a two-part model: a binary AIPW estimate of the *extensive margin* (any discount vs. none) plus a smooth B-spline dose-response curve for the *intensive margin* (discount depth, fit only on the discounted subsample). This is what `causalpipe_retail_two_part.py` implements.
- **Sepsis — estimator fix:** the outcome model now includes treatment `T` as an input feature and produces genuine counterfactual predictions (μ1, μ0) via `predict_proba`, replacing an earlier ad hoc adjustment that partially baked the raw observed treatment-control difference back into the "counterfactual" prediction (a circularity bug).
- **Sepsis — treatment-timing window:** the treatment-assignment window was corrected to only use pre-onset information, removing a source of look-ahead bias in the original cohort construction.
- **Corollary 1:** the paper's theoretical variance-advantage claim under covariate shift was independently re-verified empirically (see Estimator section above) rather than left as an unconfirmed number.

## Notes on Reproducibility

- All random seeds are fixed (seed = 42 for model fitting, seeds 0–9 for experiment repetitions).
- Seed 8 produces anomalous results in Mixed and Gradual shift conditions across all methods, including Oracle — this reflects a challenging data configuration, not a bug. Median MAE is more representative than mean for these conditions.
- Retail bootstrap uses subsamples of 50,000 from 335,437 transactions for computational feasibility.
- Sepsis analysis uses patients from Training Set A after cohort construction and propensity-overlap trimming; the pre-onset treatment window (see above) is applied consistently across all sepsis scripts.
- The small-target-sample sweep (n₂ ∈ {500, 1000, 2000, 3000}) shows confidence-interval coverage for Component-Aware degrading as n₂ grows under covariate shift (82.0% → 76.0% → 72.0% → 64.0%). This is a genuine, disclosed limitation of the current AIPW/clipping construction, not an artifact of the sweep — see `r3_major3_detection_error_mse_smallsample.py` and the corresponding discussion in the manuscript.
