# CausalPipe-Transfer
**Streaming Domain Adaptation for Causal Inference Pipelines**

This repository contains the code and reproducibility materials for the paper on CausalPipe-Transfer, a framework for estimating average treatment effects (ATE) in non-stationary streaming environments across multiple domains. This README reflects the second revision of the manuscript (KNOSYS-D-26-13508, revision 2).

## What This Paper Is About
A core challenge in applied causal inference is that real-world data distributions change over time. A causal model trained on last month's retail transactions may give misleading estimates today if customer behavior has shifted. Standard approaches either ignore this (static models) or retrain everything from scratch when drift is detected (expensive and often unnecessary).

CausalPipe-Transfer takes a different approach: it diagnoses which component of the causal pipeline has been affected by the shift (the propensity model, the outcome model, or both) and updates only that component. This selective ("Component-Aware") adaptation strategy is computationally efficient and, in some cases, more accurate than full retraining (Full-Adapt), as formalized in Corollary 1 and checked empirically (see below).

The framework is validated on three domains:

- **Synthetic benchmarks** under five types of distributional shift (covariate, label, mechanism, mixed, gradual)
- **FreshRetailNet-50K**, a fresh food retail dataset: 334,137 transactions after removing 1,300 rows with a recorded price ratio of 0
- **PhysioNet 2019 Sepsis**, ICU patient encounters from the CinC Challenge 2019 (20,324 patients after cohort construction and overlap trimming)

**1. Synthetic benchmarks**
```
python experiments/synthetic/synthetic_benchmark.py
```
**Note:** `synthetic_benchmark.py` is an earlier 10-seed version of the synthetic benchmark (five methods). It does **not** reproduce Table 3 of the paper, which reports 50 seeds and six methods (including ADWIN). The script that produced Table 3 is not included in this repository.

The number of seeds is set by `N_SEEDS` at the top of each script. Outputs are written to `results/`.

**2. Retail analysis**
```
python experiments/retail/retail_two_part_model.py
python experiments/retail/retail_robustness_checks.py     # linear-vs-spline check and placebo check
```

```
python experiments/healthcare/sepsis_owate_analysis.py
```

The first script writes `results/sepsis_owate_results.txt`, `results/sepsis_owate_convergence.csv` and `results/sepsis_owate_subgroups.csv`, and ends with a check of the subgroup table against the values reported in the paper.

## Key Results
| Domain | N | Main result | 95% CI | Significant |
|---|---|---|---|---|
| Synthetic (avg) | 5,000 events per stream | 72.4% average MAE reduction (Component-Aware vs. Source-Only, paper Table 3; not reproduced by the scripts here) | not applicable | Yes |
| Retail: extensive margin (any discount vs. none) | 334,137 | +15.6% | [15.2%, 16.1%] | Yes |
| Retail: intensive margin (discount depth, spline dose-response) | 165,984 (discounted subsample) | −25.4% (5th to 95th percentile of discount depth, W 0.008 to 0.370) | [−26.7%, −24.9%] | Yes |
| Sepsis (OWATE) | 20,324 | −3.18 pp (raw difference −7.21 pp; 55.8% attributable to confounding) | [−3.74 pp, −2.63 pp] | Yes |

Further retail results (same run):
- Unadjusted comparison: +12.3% (log scale), so the naive estimate understates the adjusted extensive-margin effect by 3.3 percentage points.
- The dose-response curve is nonmonotonic: +49.6% near W = 0.003, a trough of −14.3% near W = 0.09, and +5.0% to +8.0% at W = 0.40 to 0.45.
- Permutation placebo test (200 shuffles): p = 0.0050.
- Sensitivity with product fixed effects (760 products): −4.6% [−5.7%, −2.8%] for the 5th to 95th percentile contrast.

Further sepsis results: 20 confounders; overlap trimming to propensity scores in [0.1, 0.9] (Crump et al., 2009) keeps 99.9% of patients; the running OWATE stays within ±0.2 pp of its final value after about 5,400 patients and within ±0.15 pp after about 11,900.

## Estimator
All experiments use the same Augmented Inverse Probability Weighting (AIPW) doubly robust estimator:

```
τ̂ = (1/n) Σ_i [ μ1(Xi) − μ0(Xi) + Ti(Yi − μ1(Xi))/e(Xi) − (1−Ti)(Yi − μ0(Xi))/(1−e(Xi)) ]
```
where e(Xi) is the propensity score and μt(Xi) are counterfactual outcome predictions. Confidence intervals are computed from influence-function standard errors. The only exception is the retail intensive-margin (spline) analysis, whose confidence intervals come from 300 bootstrap replications.

**Corollary 1 (selective-adaptation variance advantage):** under covariate shift, Component-Aware adaptation (retraining only the invalidated component) has lower estimator variance than Full-Adapt (retraining everything): σ² = 0.0109 (Component-Aware) vs. 0.1102 (Full-Adapt), about 10.1 times lower. Under label shift the two are nearly identical (σ² = 0.0009 vs. 0.0009), because Component-Aware retrains the outcome model exactly as Full-Adapt does in that case. See `experiments/synthetic/corollary1_variance_check.py`.

## Shift Detection
The propensity-calibration shift detector uses two primary signals, a third mechanism-shift signal, and a documented fallback rule (Algorithm 1):

- **Covariate shift:** a single two-sample Kolmogorov–Smirnov test on the propensity score distributions of the pre- and post-shift windows (α = 0.05).
- **Label shift:** a two-sided t-test on outcome residuals from the source model (α = 0.05), together with a mean shift larger than 2 residual standard deviations.
- **Mechanism shift:** tested only if the first two signals do not fire; KS test on the residual distributions, with an explicit "otherwise → label_shift" fallback rule.

Detection accuracy: 95% (190 of 200 test cases), as reported in the paper. A dedicated small-target-sample sweep (n₂ ∈ {500, 1000, 2000, 3000}) additionally shows the single-class-propensity fallback firing only at n₂ = 500 (3/50 covariate-shift windows, 3/50 mixed, 1/50 gradual; zero at n₂ ≥ 1000). See `detection_error_small_sample_sweep.py`.

## Major Corrections in This Revision
- **Retail: zero-price rows.** The retail sample contained 1,300 rows whose recorded price ratio is exactly 0. They had been coded as complete discounts (W = 1). They are data errors and are now dropped before any other step (334,137 transactions remain). All retail numbers were recomputed.
- **Retail: discount field.** The raw `discount` column is defined by the dataset as 1.0 = full price and 0.9 = 10% off, so it is the inverse of a discount rate. The treatment variable is `true_discount = 1 − discount`. See `discount_field_diagnostic.py`.
- **Retail: model specification.** Discrete discount bins were dropped (numerically unstable near the mass point at "no discount") in favor of a two-part model: a binary AIPW estimate of the extensive margin plus a smooth B-spline dose-response curve for the intensive margin, fit only on the discounted subsample.
- **Sepsis: estimator fix.** The outcome model includes treatment T as an input and produces genuine counterfactual predictions (μ1, μ0), replacing an earlier ad hoc adjustment that was circular.
- **Sepsis: treatment-timing window.** Treatment is assigned using pre-onset information only, which removes a source of look-ahead bias.
- **Sepsis: confounders.** The model uses 20 confounders (4 vital signs, 13 laboratory values, age, heart-rate variability, and the number of hourly records). MAP, SBP, DBP, Lactate and ICULOS are excluded. The propensity model uses balanced class weights.
- **Corollary 1.** The variance-advantage claim under covariate shift was re-verified empirically (see the Estimator section).

## Notes on Reproducibility
- Model fitting uses seed 42; experiment repetitions use seeds 0 to `N_SEEDS − 1`.
- Seed 8 produces anomalous results in the Mixed and Gradual shift conditions across all methods, including Oracle. This reflects a challenging data configuration, not a bug. Median MAE is more representative than the mean for these conditions.
- The retail bootstrap resamples the discounted subsample (165,984 rows) 300 times; the placebo test uses 200 permutations.
- The sepsis analysis uses Training Set A after cohort construction and propensity-overlap trimming. The pre-onset treatment window is applied consistently across all sepsis scripts. PhysioNet 2019 Set A has no real admission timestamps across patients; file order is used as a pseudo-time axis in `sepsis_windowed_detector.py`, and it is not confirmed to be chronological.
- The small-target-sample sweep shows confidence-interval coverage for Component-Aware degrading as n₂ grows under covariate shift (82.0% → 76.0% → 72.0% → 64.0%). This is a disclosed limitation of the current AIPW/clipping construction.
